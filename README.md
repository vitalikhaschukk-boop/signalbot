# Signal Bot

Телеграм-бот торгових сигналів (Forex/Crypto OTC) з двомовним інтерфейсом (укр/рос),
підписками та адмінкою. Сигнали рахуються по реальних свічках — індикатори, а не рандом.

## Швидкий старт

```bash
cp .env.example .env        # вписати BOT_TOKEN і ADMIN_IDS
pip install -r requirements.txt
python bot/main.py
```

Тести ядра (без мережі й Telegram):

```bash
python scripts/test_core.py
```

## Змінні оточення

| Змінна | Що це |
|---|---|
| `BOT_TOKEN` | токен від @BotFather — бота реєструє **власник проєкту на себе** |
| `ADMIN_IDS` | Telegram ID через кому, кому доступна `/admin` |
| `CHANNEL_URL`, `TRADER_URL`, `PO_REF_URL` | посилання кнопок головного меню |
| `DAILY_SESSIONS` | скільки сигналів на добу дає одна підписка (дефолт 3) |
| `DATA_BACKEND` | `sim` — демо-дані, `pocket` — реальні свічки Pocket Option |
| `PO_SSID` | сесія Pocket Option; можна не ставити тут, а залити через `/admin → 🔑` |

## Структура

```
core/   config, sqlite-база, i18n (uk/ru), движок сигналів, рендер графіка
data/   market.py — інтерфейс + демо-джерело; pocket.py — реальні дані Pocket Option
bot/    main.py — меню й сесії; admin.py — /admin; keyboards.py
scripts/ test_core.py — 46 тестів; preview.py — зібрати приклад картки сигналу
```

## Адмінка

`/admin` (тільки для `ADMIN_IDS`):

- статистика: юзери, активні підписки, запити за добу, джерело даних;
- список юзерів з лічильником «скільки запитів з'їв», пошук за ID/ніком/іменем;
- картка юзера: видати підписку (Standard / VIP / Trial), зняти, обнулити денні сесії, заблокувати;
- `🔑` — залити новий SSID Pocket Option без рестарту бота.

## Дані Pocket Option

Офіційного API брокер не дає, тож свічки тягнуться неофіційним SDK по сесії (SSID)
**демо-акаунта**. Бот тільки читає котирування — жодних угод з коду. Коли сесія протухає,
дані зникають, бот каже юзеру «немає зв'язку з ринком» і не списує сесію; новий SSID
заливається через адмінку.

## Деплой

Потрібен always-on процес (long polling + websocket до брокера):

- **Northflank** free Developer Sandbox — 2 сервіси, 1 БД, компут без засинання;
- **Oracle Cloud Always Free** — своя VM (Ampere A1), але тримай CPU/пам'ять вище 20%,
  інакше Oracle має право забрати простій;
- **Fly.io** ~$2/міс — якщо не хочеться доглядати free tier.

Реєстрацію акаунтів (BotFather + хостинг) робить власник бота на себе — щоб доступи
не висіли на розробнику.
